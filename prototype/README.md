# Mirante HTML prototype

A clickable prototype of the navigation, for [milestone M1](../docs/roadmap.md#m1-html-prototype). It uses mock data, and shows web pages and API data as placeholders. It is thrown away after M1. The plan is in [docs/plans/m1-html-prototype.md](../docs/plans/m1-html-prototype.md).

## Running it

Open `index.html` in a browser. There is no build step and no server.

Changes are kept in the browser's `localStorage`. The **Reset** button at the bottom of the sidebar restores the mock data. Press `?` for the keyboard shortcuts.

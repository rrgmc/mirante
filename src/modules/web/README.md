# web module

Shows any web page as an item. See [item types](../../../docs/item-types.md#web-page).

## Item types

| Id | Name | Rendering |
|---|---|---|
| `web.page` | Web page | web |

In M2 the type is a stub with an id, a name and an icon. Its view arrives in M4.

## Connection kinds

None.

## Settings

None.

# rraidash-poc1

rraidash is a personal desktop dashboard for all of one person's work. Work is organised in groups, projects and tasks. Each task collects its Claude sessions, GitLab merge requests and pipelines, Jira issues, web pages and notes on dashboards that the user can arrange freely. It is built with Qt 6 for Windows, macOS and Linux.

The design is in [docs/README.md](docs/README.md).
